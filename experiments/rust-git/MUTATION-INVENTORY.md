# Isolated Git write inventory

This inventory precedes the mutation implementation. The existing `GitReader` stays unchanged. The next boundary operates only on fresh, private temporary repositories created by its constructor, never by admitting a caller-supplied existing path.

## Bounded implementation

1. A separate `IsolatedGit` capability creates a repository beneath canonical `/tmp`, independent of `TMPDIR`, global Git config and the live Milagre profile. Its private marker, stored filesystem identity, exact created-Worktree registry and common-directory checks guard every write. There is no constructor from an existing path, marker import, arbitrary Git command, remote fetch or push.
2. Port the existing local commit flow, including staging and index restoration inside that operation. Do not add standalone stage, unstage or discard APIs that the production renderer does not have.
3. Port Worktree list/create/status/remove under the capability. Generated destinations stay beneath its private Worktree root. Remove only registered Worktrees created by that same capability; preserve the main checkout and foreign repositories. Serialize the entire check-and-write operation across all Worktrees sharing the repository. An active owner lease blocks removal until its provider/setup user releases it.
4. Keep the domain result shapes, while leaving ProjectStates reconciliation, Chat/Link ownership, setup/copy policy, branch policy/Linear naming and session shutdown to the eventual owner adapter. This module must not advertise full `worktree:create` daemon compatibility: production also returns an updated Project and Worktree ID. Explicitly reject unsupported fields rather than silently pretending those side effects occurred.

## Validation

Use Node-generated expectations for existing commit and Worktree domain functions, with both sides operating exclusively in newly-created disposable repositories. Include literal filenames, staged `.milagre`, secret refusal/index restoration, unborn/detached/conflicted states, hook/signing errors, missing/option-like bases, safe/forced removal status checks, foreign/main/symlink paths, ownership-marker tampering, active leases, and concurrent calls. Assert the resulting Git index and file bytes directly. Keep the existing 99 read conformance cases passing. No production Git write, fetch, push, global config change or live profile access is part of these checks.
