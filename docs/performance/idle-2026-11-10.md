# Idle work on an open window, a stopped host and quiet Worktrees

Measured on 2026-11-10, macOS arm64 (Santo, load average 17 to 40 from other agents), Electron 44.5.1, Node 24.13.0.

| What                                                                    | Before                   | After                          | Change                     |
| ----------------------------------------------------------------------- | ------------------------ | ------------------------------ | -------------------------- |
| Window on a new Chat, nothing happening (GPU + renderer, one core)      | 25.2%                    | 0.6% after 40 s; 9.4% minute 1 | −97% steady, −63% minute 1 |
| Window on an open Chat, nothing happening                               | 0.3%                     | 0.3%                           | unchanged                  |
| Git work per window focus, milagre-ade (CPU of git and the host)        | 161 Worktrees, 25.7 s    | 3 Worktrees, under 0.5 s       | −98%                       |
| Host JS heap after opening milagre-ade (931 Chats), lean client         | 91 MB                    | 53 MB                          | −42%                       |
| Host left running after a stop (found on Santo: a beta.20 host, 5 days) | 1.4% CPU, 78 MB, forever | exits 3 s after the stop       | gone                       |

## What changed

- **Welcome sky** (`styles.css`): a new Chat's sparkles are SVG, which the compositor can't animate, and they looped forever, so the whole window repainted every frame. They now glint twice and the wash breathes three times (about 36 s), then the page rests.
- **Focus diff stats** (`diff-refresh.cjs`): a window focus re-read the diff stat of every Worktree with a Chat, three to eleven git processes each. Archived Chats and hidden Routine Run Chats are left out: no list shows their stat, and agent steps already refresh a Run's Worktree. In milagre-ade that is 158 of 161 Worktrees.
- **Diff base cache** (`diffstat.cjs`): the comparison branch (up to eight git processes) is kept for 5 minutes instead of 30 s, so a focus after a short pause doesn't pay it again for every Worktree.
- **First read sheds old Chats** (`project-states.cjs`): a Project read whole kept every Chat's messages for ten minutes, until the first sweep. Chats whose last message is older than the idle time now leave memory as the read finishes.
- **A stopped host exits** (`cli.cjs`, `server.cjs`): after a stop, the host only exited once its event loop emptied; one stray handle kept an old host alive, still ticking its timers. It now exits 3 s after a finished stop.

## Reproduce

```sh
npm run build:renderer --workspace milagre
npm run perf -- idle --seconds 60 --visible --new-chat               # minute one on a new Chat
npm run perf -- idle --seconds 60 --visible --new-chat --settle 40   # after the sky rests
npm run perf -- idle --seconds 60 --visible                          # an open Chat
```

`--visible` shows the window (paint and GPU cost count); `--new-chat` presses ⌘N first. Idle results now include `rssMb` per process kind. The focus figure comes from running `readDiffStat` over real Worktrees four at a time, as `DiffRefresher` does, under `/usr/bin/time`; the heap figure from a host started with `--inspect` on a copy of milagre-ade's `.milagre`, opened by a client that asked for lean states.
